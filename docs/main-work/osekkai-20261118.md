# HOME おせっかい通知（開発版）

口座一覧の月切替と別の変更。本番デプロイは未実施。

## 設定と使い方

1. 保護者のHOMEから「おせっかい通知の設定」を開き、子どもを選ぶ。家庭のowner/adminで、本人が子どもとして登録されていないアカウントに限る。対象の子はログインできるHOMEアカウントを持つ必要がある。
2. アプリ、キャラクター、曜日、時刻、再通知間隔・回数と完了条件を保存。「ひかえめ」は初回のみ、「ふつう」は追加1回まで、「うざいｗ」は追加3回まで。各人最大6件/日、最低10分空ける。時刻は日本時間。同じ時間帯で上限に達した通知もHOME内では読める。
3. 各端末で対象の子ども本人としてログインし、Chromeのメニューから「ホーム画面に追加」を選ぶ。HOMEの「おせっかい通知」から端末通知を許可・登録する。端末変更時は旧端末のHOME通知登録を解除できる。
4. 保存した設定の「テスト通知」を押す。届かなければ本人のHOMEで「いまのお誘い」とブラウザーの通知許可を確認する。子どもの端末をロックする場合は、19:45・19:55など、既存の制限開始前に、再通知0回の就寝予告を2件作る。
5. 通知本体は対象アプリを直接開く。対応環境では通知の「返事する」でHOME内の吹き出しが開く。アクションが出ない端末ではHOMEから「あとで」「しない」「できた！」を操作する。ログイン切れでは本人ログイン後に同じ通知へ戻る。別アカウントには詳細を出さず、ログイン先の切替を案内する。

宿題の完了報告には課題内容の事前登録が不要。最後の「ママよぶよ」は演出で、保護者端末への通知は別設定。服薬確認を選んだ場合、タイマーを開く・使う行為から服薬完了を判定せず、本人の明示確認を使う。薬の種類や用量の判断は行わない。

宿題は既存の学校じゅんびを使用。学校の登校日・ポイント承認とは通知の報告を独立とし、実績や承認を更新しない。九九等のお題は通知に表示し、既存アプリの難易度設定は子どもがアプリ内で選ぶ。寝る準備の返答は通知画面で受け付ける。既存の歯みがき専用画面を確認できなかったため誘導先は追加していない。キャラクターはオリジナルの名前と会話、CSSで描く4種の顔と表情を使う。OS通知には絵文字とセリフを使用する。

## 本番反映の順序

- HOME側は `0029_home_osekkai.sql` の追記のみ。既存の家族・購読・学校・薬・生活記録の変更なし。現行のHOMEソースとの差分とバックアップを確認し、先にHOMEのマイグレーションとWorkerを反映する。
- 通知センターは現行の毎分Cron、`HOME_AUTH`、VAPID、HOME端末購読、`school_push_deliveries` の配信記録を流用する。既存テーブルがない環境は `cloudflare/notification-center-api/school-preparation.sql` を確認する。現行Workerのコード・設定と差分を照合してから既存の手動デプロイで反映する。
- 端末別に本人・同じ家族の姉妹・別家庭の分離、再登録、ロック前の通知、ブラウザーを閉じた状態、端末のスリープ復帰、通知タップ、ホーム画面アイコンからの起動を確認する。元スマイルゼミ端末を含むAndroid実機の配信は未検証。Android設定のChrome通知と、ChromeのHOMEサイト通知を確認する。通知制限で届かない場合はHOME内のお誘いを使う。

## 実装と検証

- HOME Workerが通知DBへの直接アクセスを持たず、通知センターからサービスバインディングで取得する。配信前に宛先、家族権限、通知利用権限と端末セッションを確認する。日次履歴・配信ID・端末別の配信記録で再試行を識別する。
- 別アカウントでログインすると、この端末の直前のHOMEセッションを取り消す。同じ端末を別の子に引き渡す際は本人として通知を再登録する。
- 合成データで家族・姉妹間の権限、直接リンク、未認証からの復帰先、完了・辞退、服薬確認の分離、二重送信防止を確認する。

ブラウザーの合成データ試験では、子どもの切替、九九のセリフのプレビュー、設定保存、宿題の掛け合い、完了後の履歴を確認した。

自動承認レビューがWranglerのdry-runを外部送信の可能性があるとして拒否したため、その確認は中止。以後はローカルのTypeScript、esbuild、Miniflareによる検証を実施した。

服薬確認の設定は一人1件、1日1回の報告で運用する。複数薬剤・複数回服用の管理は対象外。完了した日の設定削除・作り直しでも催促を再開しない。個別の服薬条件が必要な場合は、保護者が既存のお薬管理側で確認する。

学校の30登校日記録・いいことポイントとの自動完了連携は未対応。宿題の自己報告は学校の課題チェック・ポイント承認に反映しない。歯みがき専用画面は既存の導線を確認できていない。
