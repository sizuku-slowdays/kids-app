- 既存D1 `home-db` の `learning_school_versions` は確定版追記、`learning_school_checks` は版別。通知の preferences / receipts / deliveries は既存方式を維持。

## 今回の変更

### テンプレート

`learning_school_templates` に家庭・子ども・schedule_key・revision・項目配列・更新者・日時を追記。今はdefaultのみ利用、曜日別キーは将来用。項目は追加/編集/削除/↑↓で並び替え（40件、1件60文字まで）。漢字/かん字等の表記は自由。

新しい日の宿題入力時だけ項目名を展開。ラベルだけで内容のない行は宿題にしない。日別編集はテンプレートへ書き戻さない。テンプレート変更は既存版・チェックに影響しない。同時編集はrevisionで拒否。

実ユーザーID・名前・学年に基づく自動初期データ投入は行わない。利用者の初期案は、保護者が対象の子を選び、長女用「漢字／計算／音読」、次女用「音読／かん字／さんすう」を各自のテンプレートとして保存する。全家庭共通の初期値にはしない。

### 週まとめ登録

- 子ども・対象週を選び外部で文字起こしした文章を貼り付け。外部AI API/課金/画像送信なし。
- 曜日見出し、括弧の曜日、明示日付＋曜日、Markdown表、英語曜日見出しなどに対応。日付と曜日の矛盾、対象週外、土日、日付のみで曖昧なものは未分類。日本語日付など未対応見出しも前の曜日へ誤投入しない。任意形式を完全解釈するものではなく、確認・修正が必須。
- 未分類欄から指定日に移せる。残す場合は登録しないことの確認が必要。
- 各日に現在の内容、編集内容、追加/削除候補、チェック保管の説明を表示。「変更なし / 追加 / 更新」を明示選択。登録済み日は変更なしが初期値。
- 追加は既存宿題・登校日・下校時刻を保持し、同文の件数を考慮して重複しない。更新も宿題だけを置換し、持ち物・下校時刻は保持。祝日/休校日は保護者が登校日OFF、空欄での確定も可。自動祝日判定は追加しない。
- `learning_school_imports` の一意なrequest_idとpayloadで再送を照合。**1 INSERTのトリガーで全対象日とチェック引継ぎを原子確定**。別端末の更新と競合した場合は保存しない。
- 同じ文面/種類/IDの項目は最新版へチェックを引継ぎ。変更項目のチェックは新しく開始。過去の版・チェックをDELETE/UPDATEしない。日別の従来「内容を登録・変更」は従来どおり明示再確定でチェックを新しく開始するため、画面の説明も維持。
- 週登録だけでは通知を送らず、通知設定/端末/ポイント/現金には書き込まない。

### 時間割との相互リンク

学校じゅんび→既存時間割URLへ household/child/day を渡す。HOMEの `home-mount.ts` は時間割HTMLに認証付き `timetable-link.js` だけを追加。元HTMLの画像/アップロード処理はそのまま。

時間割の追加欄は学校準備APIから本人の許可範囲だけを取得し、家庭/子ども/日付選択、週の宿題・完了表示、学校準備へのリンクを表示。画像の週・固定学年は子どもIDとの対応が未確認なので自動切替しない。画面でも画像と宿題の対象週を確認する案内を表示。
