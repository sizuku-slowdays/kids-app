# 筋肉貯金

独立ページ `/muscle-bank/`。既存HOME・ママ銀行・ポイント通帳・カレンダーのファイルは変更しない。

## 現在の公開版

- 今日やるカードから1タップ記録。運動選択は図鑑の「今日やるに追加」。画像、自由な呼び名、回数、説明、部位、タグ、URL、筋肉、覚えたを登録・編集。
- 筋肉は記録時の値を保存。編集や運動削除は過去の記録を変えない。誤入力の取消だけ筋肉を取り消す。
- 日本時間の日付で月間カレンダー、日別一覧、月間日数・筋肉・累計を表示。連続日数や体重目標なし。
- 任意の写真・ウエスト・体重・メモ。ほしいものの価格未定、欲しさ、発売予定日。筋肉達成で解放し、資金も達成したら購入可能。筋肉は消費しない。
- 基金は2026年9月、初期/現在2,013円、月目標2,000円。設定と残高更新は別。
- IndexedDBでこのブラウザにのみ保存。画像をJPEG・長辺1200pxに縮小。バックアップJSONの保存/検証付き復元。端末間同期はまだない。ブラウザ保存消去で失われるためバックアップを提供。
- サービスワーカーの範囲は筋肉貯金だけ。既存PWAキャッシュには触らない。初回オンライン閲覧後はオフラインでも使用可能。
- 初回は運動の登録から始める。存在しない画像や未登録の運動記録、Switchの発売情報は作らない。

## HOMEに接続するとき

新HOMEの実ソースとセッション仕様が未取得のため、認証済みとは表示しない。公開URLはアプリの殻のみで、写真・個人データはGitHubへ保存されない。共有端末の同一ブラウザからは端末データにアクセスできる。名前選択や `audience=mama` は本人認証として使わない。

`../cloudflare/muscle-bank-worker/README.md` の認証アダプターを新HOME実装に合わせ、本人だけ許可するテストを実施してから `config.js` のapiBaseを同一オリジン `/api/muscle-bank` に設定する。端末保存は自動でクラウドへアップロードしない。接続後、設定のバックアップ復元で本人が明示して移行する。HOME登録予定の定義は `home-integration.json`。これは権限 enforcement の代替ではない。

未接続版は実用できるが、要求されたHOME本人限定・クラウド同期の完成版ではない。
