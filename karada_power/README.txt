からだパワー UI v2

使い方
1. ZIPを解凍
2. index.html をダブルクリック
3. Chromeなどで開く

v2で追加・変更
・「筋肉マッチョ」→「マッチョ」
・カテゴリを絵文字＋子ども向け表現に変更
・食材名に読みを表示
・説明文の難しい語に読みを補助
・「主な栄養」をボタン化し、栄養ミニ図鑑を表示
・栄養から関連食材へ移動可能
・今日のパワーをポイント表示ではなくゲージ＋言葉に変更
・ゲージは栄養必要量の充足率ではなく、ゲーム上の目安と明記
・「もう少し集める？」の候補をタップ可能に変更

注意
現在の★とゲージはアプリ試作用のv1ルールです。
栄養学的な「必要量を満たした」判定ではありません。

v7 食べものを見る力版
・🍭 おやつカテゴリの試作食材を追加（きなこ大豆、プリン、アイス、クッキー、チョコ、ポテトチップス）。
・⚡ 炭水化物・脂質を「エネルギーになる栄養」として5大パワーとは別に表示。
・🥫 さば缶を加工食品の比較例として追加。
・「加工食品＝悪い」「缶詰＝添加物あり」とは判定しない。
・加工食品は「商品によって原材料・添加物・食塩などが違うので原材料名を確認」という学習導線。
・🔍 食べものを見る力（エネルギー／おやつ／加工食品／原材料）を図鑑に追加。
・アレルギー登録食材の除外ロジックは従来どおり維持。
※ おやつ・さば缶の星はUI試作用。正式版では食品成分表・商品別情報に基づき再調整する。

v8 星スコア緊急調整版
・★★★を「代表選手」に限定する方向へスコアを保守的に再調整。
・レビュー未完の旧★★★は自動的に★★へ抑制し、仮スコアが最上位に見えないようにした。
・魚、卵、大豆、肉、主要野菜、乳製品、海藻、おやつ等の代表食材を先行レビュー。
・スコアルールのversion/provenance/statusをデータに保持。
・出典表示を追加。
重要：これは「公式食品成分値の全100食材照合完了版」ではない。
文科省Excelの公式数値を捏造せず、未照合食品を★★★にしないための保守的v8。
次段階で各food_idを文科省食品番号へマッピングし、1食量を含む定量計算へ置換する。

v9 公式データ照合スタート版
・文科省 食品成分データベースの食品番号を食材に紐付け開始。
・先行確認：いわし、さば、鮭、しらす、ほうれん草、小松菜、鶏卵。
・詳細画面に「✅ 文科省データ確認済み」と100g当たりの実値を表示。
・未取得の成分は0にせず、未収載/未照合のまま保持。
・official_mapping_v9.json を追加し、今後100食材へ展開可能にした。
・次段階：脂肪酸表（DHA/EPA）を結合 → 1食量モデル → ★を定量計算。

v10 1食量スコアエンジン
・100gランキングではなく「現実的な1回量」で比較する計算基盤を追加。
・公式値がある食品は、100g値×1食gで栄養量を計算。
・★★★は複数の栄養根拠がそろわないと出にくい設計。
・欠測値は0扱いしない。
・scoring_engine_v10.json にルールと1食量を公開。
・次：脂肪酸表からDHA/EPAを食品番号で結合し、🧠スコアを完成させる。

v11.1 たまごとうふ確定
・三好食品工業「たまごとうふ」90g×3個の商品として登録。
・写真のパッケージ表面から確認できる1個90g、40kcal、たんぱく質3.4gのみ確定値として登録。
・脂質、炭水化物、食塩、その他成分は未確認のため0扱いしない。

v12 食事記録 本格版
・日付ごとに記録を保存。
・朝ごはん／昼ごはん／夜ごはん／おやつを分けて登録。
・前日／翌日／今日へ移動。
・過去記録一覧から開ける。
・図鑑のチェックは「選択中の日付＋食事」に追加。
・同じ食材を別の食事に登録可能。
・食事ごとに個別削除。
・旧 kp_today_日付 データは「以前の記録」として自動移行し、消さない。
・JSONバックアップ機能を追加。
注意：現時点は同じブラウザ内のlocalStorage保存。別端末同期は今後D1化で対応。

v15 DHA/EPA公式データ版
- 文部科学省「日本食品標準成分表（八訂）増補2023年」食品成分データベースの脂肪酸・可食部100g値を使用。
- 魚介17食品に食品番号、DHA、EPAの公式値を登録。
- 「あたま」★は、DHA+EPAをアプリ内の比較用1回量へ換算して再計算。
- 比較用1回量と★境界はアプリ独自ルールであり、国の推奨摂取量ではありません。
- ★★★: 比較用1回量でDHA+EPA 800mg以上
- ★★: 200mg以上800mg未満
- ★: 25mg以上200mg未満
- 0: 25mg未満
- rule_version: DHAEPA-2026-09-v1
